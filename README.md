Emergency Passport

An emergency assistance project built to help users access important information and resources during emergencies.

Features

Emergency-focused interface

Responsive web application

Modern and user-friendly design

Tech Stack

Frontend: React, TypeScript

Framework: TanStack Start

Styling: Tailwind CSS

Getting Started

## Getting Started

### Prerequisites

Install [Bun](https://bun.sh/).

### Installation

```bash
bun install
```

### Run Locally

```bash
bun run dev
```

Open the local URL displayed in your terminal to view the application.

You can edit the source code locally using your preferred code editor, such as VS Code.
